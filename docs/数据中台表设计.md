## 二、字段分析结论（826 篇文章实测）

分析过程中**发现并修复了两个真实数据缺陷**，这是设计优化的直接依据：

| 缺陷 | 规模 | 根因 | 修复 |
|---|---|---|---|
| 标题被解析成栏目名（"新闻中心"/"通知公告"） | **228 条** | 详情页 `<h1>` 是栏目名，覆盖了列表页真实标题 | 抽公共 `pick_title()`：命中栏目名词表则回退列表页标题 |
| 发布日期被解析成实时时钟（"今天是："） | **26 条** | 政府站 `<div class="time">今天是：</div>` 是 JS 时钟 | 政府适配器改从 `span.fbsj` / `meta PubDate` 取真实日期 |
| 正文为空 | **40 条** | 北极星详情页被**阿里云 WAF** 拦截（httpx 拿不到正文） | 改用 CDP 真实浏览器抓取，正文补齐 |
| 日期只有 `HH:MM` | **66 条** | 国际能源网 `div.time` 不含日期 | 改从 `<p class="source">日期：YYYY-MM-DD` 提取 |

**修复后数据质量**（`v_data_quality`）：

```
total_articles 826 | missing_title 0 | empty_body 0 | missing_date 0
missing_url 0      | no_province_code 120（行业源，属正常）
body_rate 100.0%   | date_rate 100.0%
```

## 三、表结构优化（6 项，均由数据实证驱动）

| # | 优化点 | 依据 | 收益 |
|---|---|---|---|
| 1 | `province_code` 允许 NULL + 冗余 `province_name` | 120 篇行业源无区划码 | 既能保留原貌，又能直接展示省份名 |
| 2 | 拆 `published_date`(DATE, 索引) + `published_ym`(CHAR7) | 时间跨度 2017-06 ~ 2026-10 | 按日/按月聚合不走函数、索引不失效 |
| 3 | `body_text` 用 `MEDIUMTEXT` | 正文实测 0 ~ 40842 字 | 规避 `TEXT` 64KB 截断风险 |
| 4 | `body_length` / `title_length` 落列 | 质量看板常查长度 | 免去每次全表 `LENGTH()` |
| 5 | `crawl_method` 落列 | 362 篇靠 CDP 浏览器攻克 | 直接回答"哪些源需要浏览器" |
| 6 | `quality_flags` 用 JSON | 替代 `VARCHAR(512)` 字符串 | 可用 `JSON_CONTAINS` 查询 |

> **踩坑记录**：列名原定 `year_month`，建表失败。实测 **MySQL 8.4 已把 `YEAR_MONTH`
> 列为保留字**（INTERVAL 间隔单位），改用 `published_ym` 规避。

## 四、库对象清单

**基础表（7）**

| 表 | 行数 | 说明 |
|---|---|---|
| `provinces` | 34 | 省级行政区维度（含港澳台） |
| `sources` | 45 | 来源维度，含 `crawl_method`（攻克方式）与 `blocker`（卡点类型） |
| `articles` | **826** | 文章事实表（唯一键 `url_hash`，跨来源去重） |
| `etl_runs` | — | 写入批次留痕 |
| `api_keys` / `audit_logs` / `stats_snapshots` | 0 | 平台自有表（与 `newsplatform/models/orm.py` 一致） |

**视图（6）**

| 视图 | 用途 |
|---|---|
| `v_province_coverage` | 省份覆盖度（来源数/文章数/时间跨度），直接支撑验收 |
| `v_source_health` | 来源健康度（攻克方式 + 卡点） |
| `v_daily_stats` | 日度产出趋势 |
| `v_monthly_trend` | 月度趋势（2026-09 达 317 篇峰值） |
| `v_category_stats` | 类别分布 |
| `v_data_quality` | 字段完整率一屏总览 |

## 六、复现命令

```bash
# 1. 字段分析（生成报告）
python scripts/analyze_fields.py

# 2. 写入中台库（自动建表建视图，幂等可重跑）
python scripts/load_platform_db.py

# 3. 清空重灌
python scripts/load_platform_db.py --truncate
```

连接信息通过环境变量注入（源码中不含任何真实口令）：

```bash
export PLATFORM_DB_USER=powernews
export PLATFORM_DB_PASSWORD='你的口令'   # 勿写入版本库
export PLATFORM_DB_NAME=powernews_platform
python scripts/load_platform_db.py
```

> 本仓库为公开仓库，数据库口令一律走环境变量或本地 `.env`（已在 `.gitignore` 中排除），
> 不在代码与文档里出现明文。
