## 七、建表优化建议

1. **行政区划代码可空**：行业源（北极星/中国电力新闻网/国际能源网）共 120 篇无区划码，表设计须允许 `province_code NULL`，并另设 `province_name` 兜底展示。
2. **正文可空但须标记**：空正文 40 条，入库时以 `quality_flags` 标记 `empty_body`，便于后续补抓，不能直接丢弃（标题+链接仍有价值）。
3. **发布时间需双列 + 精度**：现有数据均为「日」精度（YYYY-MM-DD），存 `published_at_cst` + `time_precision='day'`，避免误当秒级参与窗口计算。
4. **URL 需指纹去重**：以 URL 的 SHA-256 前 40 位做唯一键，防重复入库。
5. **正文长度跨度大**（0 ~ 40842），须用 `MEDIUMTEXT` 而非 `TEXT`。
6. **按省份/来源分层**：省份维度单列，便于按省聚合与验收覆盖度。
