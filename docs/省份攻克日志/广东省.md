## 二、攻克时间线（按发生顺序）

### 1. 阶段二 · 首轮探活

- **卡点现象**：广东电网官网 `www.gd.csg.cn` 返回 1166 字节 JS 空壳（`app.ea86c567.js`），是 **SPA + 瑞数**；HTTPS 超时、仅暴露 `/api/v1/sessions` 接口。
- **排查步骤 / 操作指令**：
  - 抓取 SPA 壳，提取入口 JS 文件名确认前端渲染；
  - 枚举南网 5 省站（gd/gx/gz/hn/yn.csg.cn），发现结构完全一致；
  - 找到唯一可静态抓的入口：**南网总部站 `www.csg.cn/xwzx/qygg/`**。
- **验证结果 / 最终方案**：判定 5 省官网不可静态抓取，改用总部站作统一兜底。
- **可复用经验**：省级子站是 SPA 时，其上级集团总部站往往是同源 CMS 且可静态抓取，是低成本兜底路径。

### 2. 阶段四 · 适配器设计

- **卡点现象**：总部站是企业公告，混有各省内容，若 5 省适配器都抓会把同一篇重复入库 5 次。
- **排查步骤 / 操作指令**：
  - 新增 `newsagg/adapters/csg_generic.py`；
  - 定义 `PROVINCE_KEYWORDS`（广东电网/广州供电局/深圳供电局/广东 → 440000 等）；
  - 实现 `accepts_title()`：按省份关键词分流，命中本省或不属于任何南网省份才收录；
  - `CSG_ARTICLE_HINT` 匹配 `/tYYYYMMDD_ID.shtml` 形态。
- **验证结果 / 最终方案**：广东电网入库 2 篇（总部站广东相关条目）。
- **可复用经验**：多省共用同一兜底源时，必须做「省份归属分流」，否则重复入库。

### 3. 阶段八 · CDP 真实浏览器攻克瑞数 412

- **卡点现象**：本站点此前受**瑞数动态防护（RiverSecurity）**拦截：HTTP 返回 412，响应体仅 2~6KB 混淆 JS（含 `$_ts` 全局变量与 `<script r='m'>`），纯 httpx 请求无法拿到正文。
- **排查步骤 / 操作指令**：
  - 启动真实 Chrome：`--user-agent=<普通 Chrome UA>` + `--disable-blink-features=AutomationControlled` + `--remote-debugging-port=9222`；
  - 确认 UA **不含** `HeadlessChrome`（headless 默认 UA 会直接暴露），且 `navigator.webdriver=false`；
  - 用 CDP `Page.navigate` 打开列表页，轮询 `document.documentElement.outerHTML.length` 直至挑战通过、DOM 渲染稳定（>2KB 且不再增长）；
  - 取渲染后 HTML 交回**既有适配器** `parse_list` / `parse_detail` 解析（解析逻辑零改动）；
  - 详情页 `<h1>` 为栏目名时，回退使用列表页标题；过滤 PDF/Office 附件链接。
- **验证结果 / 最终方案**：瑞数挑战通过，成功入库：广东电网有限责任公司（2 篇）。
- **可复用经验**：瑞数 412 只能靠真实浏览器执行 JS 挑战破解；两个关键开关——UA 去掉 HeadlessChrome、关闭 navigator.webdriver。
