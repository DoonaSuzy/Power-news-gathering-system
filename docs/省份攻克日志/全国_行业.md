## 二、攻克时间线（按发生顺序）

### 1. 阶段二 · 首轮探活

- **卡点现象**：3 个全国性行业媒体（北极星/中国电力新闻网/国际能源网）中，北极星与中国电力新闻网可正常抓取，国际能源网（in_en）返回 0 条候选。
- **排查步骤 / 操作指令**：
  - `curl -I https://www.in-en.com/` 确认 200 可达，排除网络问题；
  - 抓取首页 HTML，检索 `<a href>` 中形如 `/article/html/energy-*.shtml` 的链接；
  - `grep -o '/article/html/[a-z-]*-[0-9]*\.s?html'` 分析真实文章 URL 形态；
  - 核对适配器 in_en.py 的 `article_pattern` 与 `list_url` 配置。
- **验证结果 / 最终方案**：定位根因：列表入口取的是首页，且 `article_pattern` 未覆盖 `/article/html/energy-XXX.shtml` 形态，导致 0 条。
- **可复用经验**：门户型站点应先定位「新闻列表页」而非首页；文章 URL 形态必须实测，不能凭经验假设。

### 2. 阶段四 · 适配修正

- **卡点现象**：改用 `/news/` 入口后能发现链接，但标题被解析成站点名。
- **排查步骤 / 操作指令**：
  - 把 in_en 的 `list_url` 修正为 `https://www.in-en.com/news/`；
  - `article_pattern` 修正为 `/article/html/[a-z]+-\d+\.s?html?$`；
  - 覆写 `parse_detail()`：优先 `title_selectors`，再回退 `_title_from_head()`，并新增 `_looks_like_site_name()` 过滤站点名作为标题。
- **验证结果 / 最终方案**：in_en 由 0 → 发现 78 条、入库 40 条；三大行业媒体合计 120 篇。
- **可复用经验**：详情页 `<h1>` 常是站点名而非文章标题，需显式过滤；标题提取要有「首选选择器 + 兜底 + 黑名单」三层。

## 三、经验沉淀（本省专项）
