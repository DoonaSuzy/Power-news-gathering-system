## 二、攻克时间线（按发生顺序）

### 1. 阶段二 · 首轮探活

- **卡点现象**：HTTPS 请求 `https://www.tj.sgcc.com.cn/p1/` 报 ConnectError，DNS 解析落到 198.18.x 保留网段，判定为「网络不可达」。
- **排查步骤 / 操作指令**：
  - `nslookup www.tj.sgcc.com.cn` 观察解析结果；
  - 双协议探测：分别请求 `https://` 与 `http://`；
  - 发现环境变量 `http_proxy=http://127.0.0.1:35004`（沙箱代理）劫持 TLS 握手。
- **验证结果 / 最终方案**：确认 HTTPS 被阻断、仅 HTTP(80) 可达；此为网络环境问题，非代码缺陷。
- **可复用经验**：国网省级站群在本网络下 HTTPS 不可用，必须准备 HTTP 降级路径。

### 2. 阶段六 · 关代理后重试

- **卡点现象**：用户关闭代理后重试，HTTPS 仍 ConnectError，但 HTTP 返回 200。
- **排查步骤 / 操作指令**：
  - 在 `crawl_and_archive.py` 顶部 `os.environ.pop('http_proxy'/'https_proxy'/...)`；
  - httpx 客户端统一 `trust_env=False`，绕过系统代理；
  - 实现 `candidate_list_urls()`：对同一路径自动 http/https 互备。
- **验证结果 / 最终方案**：HTTP 探测 200/58901 字节；列表页 found 49、入库 40 篇。
- **可复用经验**：抓取国网必须三件套：清代理变量 + trust_env=False + 协议降级。
