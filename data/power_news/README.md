### ⚠️ 受限于网络环境（25 个国网省级站点）

`*.sgcc.com.cn` 全部 26 个国网省级站点在本机解析到保留网段（198.18.x），
**TCP 层无法连通**，与代码无关。网络环境恢复（关闭 VPN/TUN 或改用可直连网络）
后直接重跑 `crawl_and_archive.py` 即可。

### ⚠️ 需浏览器渲染（南网 5 省 + 港澳台）

- 南方电网省级公司站（`*.csg.cn`）为 **SPA + 瑞数类动态防护**，静态抓取仅得
  1166 字节 JS 空壳。当前策略：统一从**南网总部站** `www.csg.cn` 采集，
  按省份关键词分流（已验证）。
- 香港中电（403）、澳门电力（SPA）、台电（不可达）需浏览器渲染方案。

## 四、复现命令

```bash
# 全量抓取（默认每源 25 篇）
python scripts/crawl_and_archive.py --out data/power_news

# 指定来源 / 调整上限
python scripts/crawl_and_archive.py --source bjx --source sgcc_sc --limit 50

# 网络恢复后重抓国网
python scripts/crawl_and_archive.py --source sgcc_bj --source sgcc_js --limit 30
```
